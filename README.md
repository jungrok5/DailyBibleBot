# 성경통독 (DailyBibleBot)

주말·명절·고난주간을 뺀 평일에 **하루 3장씩** 읽는 통독표와 카카오톡 공유 도구.

이전에는 리딩지저스 영상 일정을 그대로 따랐지만, 하루 분량이 4장에서 7장까지
들쭉날쭉해 꾸준히 읽기 어려웠다. 이 버전은 분량을 낮게 고정하는 쪽을 택했다.
1년을 넘기더라도 매일 부담 없이 읽히는 것이 목적이다.

## 통독표

| 항목 | 값 |
|---|---|
| 총 일수 | **420일** |
| 하루 장 수 | 3장 고정 (책 마지막 날만 1~2장) |
| 하루 분량 | 평균 74절 |
| 기간 | 2026-10-05 시작 → 2028-06-06 완독 (**약 20개월**) |

장 수 분포: 3장 354일 / 2장 61일 / 1장 5일.
2장 이하인 날은 책의 마지막 날이다. 1장인 날 5일은 오바댜·빌레몬서·요한이서·
요한삼서·유다서로, 원래 한 장짜리 책이다.

설계 원칙 네 가지:

1. **하루 3장 고정.** 분량을 낮게 잡아 꾸준히 읽는 것을 우선한다.
2. **하루 분량은 두 권에 걸치지 않는다.** "창세기 49-50장 + 출애굽기 1장" 같은
   배정이 없다. 한 권을 끝내고 다음 권으로 넘어간다. 그래서 책마다 마지막 날은
   1~2장이 될 수 있다.
3. **한 권 안에서는 고르게 나눈다.** 4장짜리 룻기는 (3,1)이 아니라 (2,2)로 읽는다.
4. **날짜를 박지 않는다.** 통독표는 순번(1일차, 2일차…)만 갖는다. 진도는 공유
   버튼을 눌렀는지로 나가고, 날짜는 어디까지 왔는지 가늠하는 안내용이다.

### 기간에 대해

주 5일에서 설·추석·고난주간을 빼면 읽을 수 있는 날이 **연 250일** 남는다
(2027년 252일, 2028년 249일). 420일이면 **약 1년 8개월**이 걸린다.

성경은 1189장이라 **평일만 읽으면 쉬는 날이 하루도 없어도 하루 평균 4.6장이
최소**다. 1년 1독과 하루 3장은 같이 갈 수 없어서, 분량을 택하고 기간을 늘렸다.

## 통독표 바꾸기

`scripts/generate-plan.mjs` 맨 위 상수 하나가 전부다.

```js
const CHAPTERS_PER_DAY = 3;
```

고친 뒤 `npm run plan` 을 돌리면 `public/reading_plan.json` 이 다시 만들어진다.
책 경계를 지키느라 자투리가 생기므로 단순히 1189을 나눈 값보다 길다.

| 하루 장 수 | 총 일수 | 연 250일 기준 |
|---|---|---|
| 2장 | 609일 | 약 2년 5개월 |
| **3장** | **420일** | **약 1년 8개월** |
| 4장 | 321일 | 약 1년 3개월 |
| 5장 | 266일 | 약 1년 1개월 |
| 6장 | 224일 | 약 11개월 |

## 시작일 · 휴일 바꾸기

`src/schedule.js` 위쪽에 있다.

```js
export const START_DATE = '2026-10-05';   // 이 날이 1일차
export const SEOLLAL = { 2026: '2026-02-17', ... };
export const CHUSEOK = { 2026: '2026-09-25', ... };
```

- 주말과 고난주간(부활절 직전 월~토)은 자동으로 빠진다.
- 설·추석은 음력이라 표로 넣어야 한다. 당일 기준 앞뒤 1일씩 3일을 쉬는 것으로 계산한다.
- **표가 조금 틀려도 통독표는 깨지지 않는다.** 진도는 공유 기록으로 나가기 때문에
  예상 날짜 표시만 며칠 밀린다. 해가 바뀔 때 공휴일 공고를 보고 고쳐주면 된다.
- 420일은 2032년까지 가므로, 표의 연도를 그때그때 이어서 채워주면 된다.

## 공유 기록

카카오톡 공유 버튼을 누르면 그 일차가 **공유함**으로 표시되고 브라우저
`localStorage`(`biblebot.shared.v1`)에 남는다. 며칠 쉬었다 들어와도 어디까지
공유했는지 바로 보이고, 화면이 자동으로 다음 분량으로 이동한다.

- 카카오는 공유 완료 여부를 돌려주지 않는다. **버튼을 누른 것을 공유로 본다.**
- 잘못 눌렀으면 카드를 열어 `공유 안 함으로 되돌리기` 를 누르면 된다.
- 헤더 우측 버튼으로 전체 기록을 초기화한다.
- 기록은 이 브라우저에만 남는다. 기기를 바꾸면 이어지지 않는다.
- 카카오 SDK 를 못 불러오면 공유 문구를 클립보드에 복사하는 것으로 대체한다.

## 개발

```bash
npm install
npm run plan     # 통독표 생성 → public/reading_plan.json
npm run dev      # 개발 서버
npm run build    # plan + vite build → dist/
npm run preview  # 빌드 결과 미리보기
```

`npm run build` 가 통독표 생성을 포함하므로 Vercel 에서도 그대로 빌드된다.
